# Barrel flange-doubler accounting and undrawn reinforcement provenance

The census labels the flangeDoubler barrel bill line **not independently drawn**. This paper traces that specific accounting-to-physical correspondence gap; the source table remains the sole location of its numerical area and mass entries.

The source path is first-solve baseline **aOe1**, then the **flangeT** density/barrel-domain accounting conversion, the **flangeDoublerT** skeleton return, ordinary member aggregation and the **flangeDoubler** ledger key with the source joint-adder convention. These are conditional source identities, not an actual flange section or installed reinforcement. The later reserve-difference expression is separate; it is not this baseline return and is not mapped here. No conversion factor, numerical quantity or model result is copied or calculated.

[CROSSWALK.json](CROSSWALK.json) preserves source identities separately from actual records and requirements. [PROVENANCE.json](PROVENANCE.json) pins the source revision/bytes and declares the one-based, end-exclusive locator convention. Sources: [member census](../../../docs/MEMBER-CENSUS.md), [model source](../../../ship/model.js), and [root README](../../../README.md). No source or generated census is modified or executed.
