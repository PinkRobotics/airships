# Thermal installation boundary and evidence

The [verification plan](../../../docs/VERIFICATION-PLAN.md#needs-an-expert) names unpriced ducting, coolant loops and bay ventilation for configured machinery on an ambient-pressure raft outside the vacuum. Its [requested thermal evaluator](../../../docs/VERIFICATION-PLAN.md#what-we-would-ask-external-evaluators) asks what those duty cycles require and what the complete cooling system weighs at the working altitude. This paper records that existing evidence boundary without selecting an installation or estimating its performance.

The ground-plant comparator in the same evaluator section is hardware with supplied cooling, matched by input power. The source explicitly says it is not a complete airborne-system estimate. That comparator cannot establish matched airborne heat rejection or supply the missing duct, loop, bay and support evidence by itself. No nitrogen performance or plant/source-mass comparison is repeated here.

The plan also [states that thermal analysis exists while cooling-installation mass stays open](../../../docs/VERIFICATION-PLAN.md#what-the-analysis-changed). [EVIDENCE-MAP.json](EVIDENCE-MAP.json) preserves the assertion and the exact documented source/filename locator trace. The assertion supplies no direct installation-analysis locator. No applicable result is inferred or regenerated. Any unlocated artifact remains a scoped coverage gap; this is not a claim that no analysis exists elsewhere.

[The member census](../../../docs/MEMBER-CENSUS.md) retains drawing/bill disagreements and unknown counterparts; it does not supply complete thermal-support observations. Its model quantities are not recalculated, reallocated or copied into a new installation bill. The [repository README](../../../README.md) keeps conceptual illustration and repository checks separate from built or validated hardware. [PROVENANCE.json](PROVENANCE.json) pins these unchanged sources.
