# Mass budget source outputs source names versus acquired invocation custody

This paper traces selected source identities in [tools/gen_mass_budget_prose.py](../../../tools/gen_mass_budget_prose.py). [CROSSWALK.json](CROSSWALK.json) records exact nonnumeric fragments, hash-only declaration context and prospective missing records. [PROVENANCE.json](PROVENANCE.json) pins the complete authorized sources and revision.

Only the selected `outputs` function declaration name is recorded. Formal parameter names and inventories are omitted. Equal spelling elsewhere establishes no same lexical binding. Source names are not acquired face, plane, graph, tree, member, article, material or geometry records, or numerical, manufacturing, structural or physical qualification.

Defaults/default references, type annotations/body/docstring/internal bindings/callees/member-node-material-coordinate-index/return inventories, dimensions/output/selected graph/tree/article/material/property/problem/path/file/vertices/triangles/header/SDF/parameter-set/geometry/state/member/node/kind/display/frame/axis/offset/cut-list/numeric values/traversal/algorithm/operators/formulas are omitted. Source hashes identify text without acquiring actual invocation, configuration, inputs or outputs.
