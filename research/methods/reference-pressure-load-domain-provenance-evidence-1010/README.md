# Reference pressure and load-domain provenance

Date: 2026-10-10. Status: prospective evidence, OPEN. [ship/model.js](../../../ship/model.js) defines `P_ATM`, default pressure arguments in `panelTension`, `faceShares` and `memberDemands`, and fixed `P_ATM` references inside `shipWall` and `shipSkeleton`. These are source input identities, not observations of actual internal or external pressure, an adopted service envelope or a validated differential-load case. No numeric source value is repeated or evaluated.

The [evidence contract](EVIDENCE.json) keeps nominal constant, optional argument, fixed reference use and actual differential/load-domain records separate. Every actual datum, reference-standard adoption, configuration, frame, state/time, instrument/calibration, raw differential, uncertainty, applicability/load-boundary, custody, owner and criterion/adoption record remains null/UNKNOWN.
