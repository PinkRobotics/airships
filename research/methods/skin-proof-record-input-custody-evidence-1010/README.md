# Skin proof record source names versus acquired input custody

This paper traces selected source identities in [tools/gen_skin.py](../../../tools/gen_skin.py). [CROSSWALK.json](CROSSWALK.json) records exact nonnumeric fragments, hashed contexts and prospective missing records. [PROVENANCE.json](PROVENANCE.json) pins the complete authorized sources and revision.

The selected `proof` function declares its own `name`, `ok` and `detail` parameters. `PROOFS` is separately a module source binding name. Function parameters and module binding occupy separate namespaces; equal spelling elsewhere does not establish identity. Source labels are not independent proof, an actual success criterion, an acquired verdict or qualified measured skin.

Printed labels and format-string text, bool/append/print/return operations, control logic, actual flags/record lists/verdict inventory and all algorithms are omitted. Source pins and hash-only contexts identify text without acquiring an actual invocation or record.
