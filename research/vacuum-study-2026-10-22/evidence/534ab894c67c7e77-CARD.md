With equal faces, h = tc + tf, sigma0 = E h / [R sqrt(1-nu²)], sigma_crimp = h² Gc / (2 tf tc), and Vc = sigma0/sigma_crimp. Kc = 1-Vc/4 through Vc=2 and 1/Vc above it. Pressure capacity is 4 tf gamma Kc sigma0/R. The optimistic gamma is 0.2+0.4 min(Vc,2); conservative gamma is 0.2. The implementation never stacks a second knockdown.

Face compression uses 4 sigma tf/(pR), and core crush uses strength/(p/2), retaining the inherited model. Wrinkling uses the independently solved equibiaxial root b³+b=1, b=0.6823278038280193: honeycomb stress b*0.33*sqrt(E Ec tf/tc), foam stress b*0.50*[E Ec Gc/(1-nu²)]^(1/3). Stress safety factors divide by pR/(4tf). Mass is 1.05*4*pi*R²*(2*rho_face*tf+rho_core*tc)+100 kg.

The bare crimp value in the owner's mode dictionary is deliberately unmodified. On the conservative crimp branch the effective design crimp allowable is gamma times that value, and equals global buckling. These represent one mechanism when finding the next distinct mode. RESULTS.json makes both the bare value and effective mode explicit.
